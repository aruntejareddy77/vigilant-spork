# Plan 03-03: Secure Isolated Code Sandbox & Workflow Management CLI

## Objective

Implement the secure isolated Python code execution sandbox and operator workflow CLI commands for the Sovereign AI Workbench. Build `CodeSandbox` enforcing strict resource bounding (timeout, CPU/RAM ceilings), ephemeral directory isolation, and mathematical zero-network egress across Linux production (`unshare -n` network namespaces) and Windows local development (restricted subprocesses with socket blocks and static AST network import rejection). Expose workflow execution, suspension/resumption, and tool management subcommands via the sovereign CLI.

## User Story Framing

**As an** industrial AI security auditor and plant engineer,  
**I want** agent-generated Python scripts to run inside a deeply isolated execution sandbox that physically cannot communicate with the network, cannot run away in infinite loops, and cannot touch host system files,  
**So that** dynamic engineering mathematics and data processing can be executed autonomously with guaranteed safety.

<threat_model>
### ASVS & STRIDE Threat Modeling

- **OWASP ASVS Category:** V12.3 (File Execution), V14.2 (Dependency Configuration), V1.4 (Access Control Architecture).
- **Threat T-03-01 (STRIDE: Information Disclosure / Egress):** Generated Python code attempts to establish outbound TCP/UDP network connections (e.g. data exfiltration).
  - *Mitigation:* Multi-tier defense: On Linux, the process is isolated via `unshare -n` with only loopback (no outbound routing); on Windows, pre-execution static AST analysis blocks socket and HTTP library imports (`socket`, `urllib`, `requests`, `http.client`), and environment variables containing credentials/proxies are stripped.
- **Threat T-03-02 (STRIDE: Denial of Service):** Generated code executes an infinite loop (`while True:`) or allocates excessive memory.
  - *Mitigation:* Subprocess is executed with a hard execution timeout (default 15.0s). If the timeout expires, the process tree is forcefully terminated (`SIGKILL` / `taskkill`), and the result records `timed_out = True`.
- **Threat T-03-09 (STRIDE: Tampering):** Generated code writes persistent malicious files onto the host server filesystem.
  - *Mitigation:* Code executes inside an ephemeral workspace directory that is completely deleted after output capture.
</threat_model>
