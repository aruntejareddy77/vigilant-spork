# Plan 05-02: Multi-Pane Web UI with Zero-External-CDN Air-Gap Strategy & Guided Demo Modes

## Objective

Deliver the air-gapped, multi-pane web operations console for the Sovereign AI Workbench. Implement a 100% self-contained web architecture in `src/sovereign/server/static/` with zero external CDN dependencies—eliminating all external script, stylesheet, webfont, and icon requests to strictly preserve air-gap isolation and prevent accidental egress alerts. Construct a responsive four-pane dashboard with real-time WebSocket connectivity: (1) live agent reasoning trace timeline, (2) interactive HTML5 `<canvas>` document preview rendering normalized bounding boxes (color-coded for printed, handwritten, $<0.85$ confidence review flags, and visual drawing revision diffs), (3) Human-in-the-Loop (HITL) approval queue with operator review notes, and (4) real-time network egress telemetry monitor with ALLOW/DENY badges and synthetic probe triggers. Implement dynamic RBAC view filtering that strictly removes task submission and approval controls in Auditor mode. Construct the guided SIH demonstration workflow controller providing one-click, step-by-step execution for Demo A (Inspection Report $\rightarrow$ Approval Note), Demo B (Industrial Code Generation & Isolated Sandbox Execution), and Demo C (P&ID Drawing Diff & Overlay).

## User Story Framing

**As an** industrial operations engineer or compliance auditor in a disconnected control room,  
**I want** an intuitive, multi-pane single-page web console that renders completely offline without any internet asset downloads,  
**So that** I can track live agent reasoning steps, visually inspect document and drawing extractions with spatial bounding boxes, approve sensitive deliverables before release, observe real-time proof of zero network egress, and execute guided end-to-end demonstrations with a single click.

<threat_model>
### ASVS & STRIDE Threat Modeling

- **OWASP ASVS Categories:**
  - V5.1 (Input Validation & Output Encoding): All dynamic data inserted into the DOM is escaped via native DOM APIs or text node assignment to prevent Cross-Site Scripting (XSS).
  - V13.1.1 (Generic Web Service Architecture): Zero external resource loading eliminates third-party script injection and subresource integrity failure.
  - V4.1.1 (Access Control Enforcement): Presentation-layer RBAC filtering enforces least privilege in conjunction with backend 403 API guards.

- **Threat T-05-01 (STRIDE: Information Disclosure / Denial of Service):** Browser attempts to fetch external assets (e.g., Google Fonts, FontAwesome, unpkg/cdnjs libraries) upon page load. In an air-gapped network with default-deny rules (SOVG-04), this causes rendering timeouts, broken layouts, and trips `NetworkMonitor` to generate high-severity egress alerts.
  - *Mitigation:* 100% zero-external-CDN policy. All assets reside locally in `src/sovereign/server/static/`. All fonts use the OS-native system font stack. All UI icons are defined as inline SVGs. Automated static analysis (`test_static_assets.py`) scans all static files and fails if any `http://`, `https://`, or `//` URL is detected.

- **Threat T-05-06 (STRIDE: Elevation of Privilege / Tampering):** Auditor uses browser developer tools to unhide or enable the "Submit Task" button or approval controls in the DOM.
  - *Mitigation:* While the Web UI dynamically hides and disables unauthorized controls in Auditor mode, the backend REST API independently enforces `require_role(UserRole.ENGINEER)` (implemented in Plan 05-01). Any tampered submission directly returns HTTP 403 Forbidden and logs an immutable `SECURITY_ALERT_RBAC_VIOLATION` in the audit ledger.

- **Threat T-05-07 (STRIDE: Spoofing / Cross-Site Scripting):** Malicious inspection text or drawing annotations extracted by OCR contain `<script>` tags, causing XSS when rendered in the reasoning trace or document preview.
  - *Mitigation:* The frontend uses native `textContent` assignment and canvas drawing primitives instead of `innerHTML` for untrusted model and OCR strings, neutralizing script injection vectors.
</threat_model>
