# Plan 04-03: Native Office Deliverable Generators, Reproducible Code & Calculation Trace Export

## Objective

Implement the native industrial deliverable generation suite for the Sovereign AI Workbench. Build `DocxDeliverableGenerator` to produce professional Microsoft Word (`.docx`) approval memos with corporate typography, zebra-striped findings tables, and citation appendices. Build `XlsxDeliverableGenerator` to create Microsoft Excel (`.xlsx`) workbooks featuring *live, recalculable mathematical formulas* and color-coded input/calculation/pass-fail tiers, protected against formula injection attacks. Build `PptxDeliverableGenerator` to generate executive briefing decks featuring *native editable OOXML charts* rather than static raster images. Build `CodeArtifactExporter` to bundle verified runnable Python scripts with execution traces and test fixtures in `/local/output`. Build `CalculationTraceExporter` to format step-by-step engineering derivations (ASME B31.3). Integrate all generators with Phase 1 `LineageEngine` to embed cryptographic provenance properties directly into `docProps/custom.xml` and emit sibling `.lineage.json` manifests.

## User Story Framing

**As a** plant operations manager or senior mechanical engineer,  
**I want** AI-generated deliverables produced in native Microsoft Office formats (.docx, .xlsx, .pptx) with live formulas and editable charts,  
**So that** my engineering team can inspect formulas, perform what-if recalculations by altering input cells, edit presentation charts directly during review meetings, and audit complete mathematical derivations without accepting static opaque numbers.

<threat_model>
### ASVS & STRIDE Threat Modeling

- **OWASP ASVS Category:** V5.1 (Input Validation), V5.2.4 (Memory Bounds), V10.3 (Application Integrity).
- **Threat T-04-02 (STRIDE: Tampering):** Malicious or untrusted text extracted from OCR or user prompts beginning with formula trigger characters (`=`, `+`, `-`, `@`) triggers Dynamic Data Exchange (DDE) formula injection or remote command execution when the generated `.xlsx` workbook is opened in Microsoft Excel.
  - *Mitigation:* Strict Formula & Macro Sanitization. The `XlsxDeliverableGenerator` strictly delineates literal data cells from calculated formula cells. Any textual string starting with `=`, `+`, `-`, or `@` is escaped with a leading apostrophe (`'`), disabling formula evaluation. Only explicitly typed `formula_excel` parameters configured through authorized calculation builders are written as active formula strings.
- **Threat T-04-04 (STRIDE: Tampering):** Directory traversal during deliverable file export: An agent or task crafts an output path (e.g. `../../../../etc/cron.daily/malicious.py` or system directory overwrites) outside the intended deliverable root.
  - *Mitigation:* Strict Path Fencing. All deliverable generators resolve destination paths and verify `Path(output_path).resolve().is_relative_to(output_directory)`. Violations immediately raise `PathSecurityViolation` and record a high-severity security alert in the audit ledger.
</threat_model>

## Multi-Source Coverage Audit

- **Requirements Covered:**
  - `DELV-01`: System generates native Microsoft Word (.docx) documents with structured headings, formatted findings tables, and corporate styling (FR-DG-1).
  - `DELV-02`: System generates native Microsoft Excel (.xlsx) workbooks with live mathematical formulas, cell references, and recalculable sheets (FR-DG-2).
  - `DELV-03`: System generates native Microsoft PowerPoint (.pptx) decks with styled slide layouts and editable native charts (FR-DG-3).
  - `DELV-04`: System exports reproducible code artifacts accompanied by verified execution logs and sample data inputs in `/local/output` (FR-DG-4).
  - `DELV-05`: System exports verifiable engineering calculation traces detailing applied standard clauses, input variables, and intermediate math steps (FR-DG-5).
- **Research Decisions Implemented:**
  - Full reliance on pure-Python OOXML libraries (`python-docx`, `openpyxl`, `python-pptx`) requiring zero desktop Office or LibreOffice binaries.
  - Excel workbooks with live recalculable formula cells (e.g. `=B4*B5/(2*(B6*B7+B4*B8))`) and color-coded input (Soft Blue `#D9E1F2`), formula (Soft Amber `#FFF2CC`), and pass/fail (Soft Green `#E2EFDA`) styling.
  - PowerPoint decks utilizing native `CategoryChartData` OOXML chart parts allowing interactive data editing.
  - Mandatory lineage embedding via Phase 1 `LineageEngine` into `docProps/custom.xml` and W3C PROV-O sidecars.
