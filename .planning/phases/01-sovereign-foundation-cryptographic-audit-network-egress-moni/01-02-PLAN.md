# Plan 01-02: Network Egress Monitoring & Policy Engine

## Objective

Deliver the network isolation and real-time observability engine for the Sovereign AI Workbench. Implement a declarative network policy (`network_policy.yaml`) enforcing default-deny egress rules, a cross-platform `psutil` socket connection monitor with process attribution, an in-memory 10,000-event circular ring buffer, a WebSocket telemetry streaming server, an automatic audit ledger escalation sink for connection denials, and an automated multi-protocol synthetic egress test harness (`sovereign test-egress`).

## User Story Framing

**As a** security administrator or SIH evaluation judge,  
**I want** observable, verifiable real-time proof that the Sovereign AI Workbench blocks 100% of outbound connections to the internet,  
**So that** confidential industrial documents, model weights, and proprietary queries cannot leak across network boundaries.

<threat_model>
### ASVS & STRIDE Threat Modeling

- **OWASP ASVS Category:** V1.4 (Access Control Architecture), V14.2 (Dependency Configuration).
- **Threat T-01-04 (STRIDE: Information Disclosure):** A compromised LLM model, malicious Python dependency, or agent tool attempts an outbound HTTP/S request, DNS lookup, or raw TCP connection to exfiltrate proprietary data.
  - *Mitigation:* Declarative default-deny policy dropping all public IP addresses and external DNS (UDP/TCP port 53). In containers, kernel-level iptables drops outbound packets. On host runtimes, the `NetworkPolicyEngine` validates connections and immediately logs security alerts to `audit_ledger.jsonl`. Automated probe suite (`sovereign test-egress`) confirms denial.
- **Threat T-01-05 (STRIDE: Denial of Service):** High connection churn or network packet storms exhaust memory or overwhelm disk I/O on the audit ledger.
  - *Mitigation:* Telemetry events are stored in a fixed-size, circular in-memory buffer (`collections.deque(maxlen=10000)`). High-frequency benign connections (loopback IPC) are kept purely in memory; only policy DENY events write to disk.
</threat_model>

## Multi-Source Coverage Audit

- **Requirements Covered:**
  - `SOVG-03`: Real-time visible network monitor dashboard tracks socket connections and kernel-level network attempts with explicit allow/deny outcomes.
  - `SOVG-04`: Host and container network configurations enforce default-deny egress policies blocking all non-intranet/non-localhost routes.
- **Locked Decisions Implemented:**
  - `D-05`: Layered Strategy: Native Linux Kernel (eBPF/Tetragon & iptables) + Cross-Platform Socket/psutil Monitor for Dev/Windows.
  - `D-06`: Declarative Network Policy (`network_policy.yaml`) defaulting to Localhost + Configurable Intranet CIDR.
  - `D-07`: Fast In-Memory Ring Buffer (10,000 slots) + WebSocket Streaming + Audit Ledger Sink on Deny.
  - `D-08`: Comprehensive Multi-Protocol Egress Test Suite (`sovereign test-egress`: DNS 53, HTTP/S 80/443, NTP 123, raw sockets).
