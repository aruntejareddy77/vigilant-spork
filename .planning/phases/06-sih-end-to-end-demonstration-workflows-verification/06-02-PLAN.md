### ASVS & STRIDE Threat Modeling

- **OWASP ASVS Categories:**
  - V1.4.1 (Access Control Architecture): Universal 3-tier role hierarchy (Admin $\ge$ Engineer $\ge$ Auditor) enforced across REST, CLI, and SDK.
  - V4.1.1 (Access Control Enforcement): Auditor clearance blocked from all mutating actions (`POST /api/tasks`, `POST /api/demos/*`, `POST /api/tasks/{id}/resume`) with HTTP 403 Forbidden.
  - V10.3 (Audit Trail Integrity): Cryptographic SHA-256 hash chaining over RFC 8785 canonical JSON; any tampering or out-of-order writes fail verification immediately.
  - V13.1.1 (Generic Web Service Security): Server binds strictly to `127.0.0.1` and authorized intranet CIDRs; Host header validation prevents DNS rebinding.
  - V14.2 (Air-Gap Sovereignty): Kernel and socket inspection verifies zero unauthorized outbound packets during multi-workflow execution.

- **Threat T-06-01 (STRIDE: Elevation of Privilege):** An Auditor or unauthorized user executes curl or SDK scripts to bypass UI controls, attempting to launch demos or sign off on suspended approval gates.
  - *Mitigation:* FastAPI `require_role(UserRole.ENGINEER)` dependency injection checks cryptographic tokens/headers on every mutating route. Auditor attempts return HTTP 403 Forbidden, raise `RBACPermissionError` in SDK, and immediately append a high-priority `SECURITY_ALERT_RBAC_VIOLATION` event to the `AuditLedger`.

- **Threat T-06-02 (STRIDE: Repudiation / Audit Tampering):** Malicious insider modifies an intermediate event payload in `audit_ledger.jsonl` (e.g., changing an inspection finding or approval timestamp) to conceal unauthorized actions.
  - *Mitigation:* `verify_ledger()` recomputes SHA-256 hash chains from sequence 0 to tip. The tamper test asserts that modifying any record byte causes verification to fail closed with `is_valid=False` and correctly isolates the exact corrupt sequence number.

- **Threat T-06-03 (STRIDE: Information Disclosure / Egress Leak):** Background threads or imported packages attempt phone-home analytics, update checks, or DNS resolution during long-running demonstration sessions.
  - *Mitigation:* `NetworkMonitor` background polling daemon samples OS sockets every $250\,\text{ms}$, evaluating connections against `NetworkPolicyEngine`. Any outbound socket to a non-loopback/non-intranet destination triggers an immediate `SECURITY_ALERT_EGRESS_VIOLATION` in the ledger and increments the egress leak counter.

- **Threat T-06-04 (STRIDE: Path Traversal in Deliverable Retrieval):** Evaluator or client script requests deliverable downloads with path manipulation strings (e.g. `../../../../etc/passwd`).
  - *Mitigation:* `SovereignClient.download_artifact()` and server route `download_artifact` validate destination paths against `allowed_root` using `Path.resolve().is_relative_to()`, rejecting traversal attempts with HTTP 400 / `ValueError`.
</threat_model>
